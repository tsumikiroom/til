# 物性で語るファブリック

エンジニア向けに、ファブリックを「数値で扱える素材」として見るための主要パラメータ。素材選定時に**カタログ / 仕様書のどこを読むか**の指針。

## 1. 透光率 (Light Transmittance)

光がどれだけ透過するか。**%表記**。

| %範囲 | 性質 | 用途例 |
|------|------|--------|
| 90%+ | ほぼ透明 | チュール、極細メッシュ |
| 50〜80% | 半透明 (シャドウグラフ可) | リアプロ用シフォン |
| 20〜50% | 影は通すが像は通さない | プロジェクション幕の標準域 |
| 0〜20% | ほぼ遮光 | 暗幕、舞台幕 |

**測定**: 分光光度計 (一般人は使えない)。実用上は**メーカー公表値**を信じる、または現場で照明を当てて目視確認。

**ハーフミラー的素材**: 片方向だけ透ける布 (法線方向に依存) もある。ステージ演出で使う。

## 2. 反射率と拡散性

投影面として使う場合に重要。

- **ゲイン (Gain)** = 鏡面に対する反射比。1.0 が標準、1.5 で高反射、0.7 で低反射 (拡散性高い)
- **ハーフゲイン角** = ゲインが半分に落ちる視角。広いほど多方向から見える
- **HK 値 (拡散反射率)** = 朝鮮人参…ではなくマット度を表す指標。低いほど鏡面に近い

LT 中で深掘りしすぎない (聴衆に拒否反応出る)。「反射率と拡散度」とだけ言って数値は補足資料へ。

## 見え感を理解する — 反射・拡散・透過 (どこに注目すべきか)

数値の前に、まず「**なぜ布によって見え感・風合いが違って見えるのか**」を掴んでおくと素材選びの軸ができる。布に当たった光は、おおまかに 3 つに分かれる。

- **反射 (鏡面 / specular)** — 表面でツルッと跳ね返る。光沢・ハイライトとして見える
- **拡散 (diffuse)** — いろいろな方向に散る。マットで均一な明るさに見える
- **透過 (transmission)** — 裏へ抜ける。透け・奥行き・逆光のやわらかさになる

この **3 つの配分**が見え感を決める。そして配分を決めるのは:

1. **材料 (繊維・糸)**: 絹 / 合成のフィラメントは光沢 (反射寄り)、綿 / 麻のスパン糸は毛羽で拡散寄り
2. **組織 (構造)**: ここの効きが**とても大きい**。同じ糸でも織り方で激変する
   - **朱子織**: 経糸が長く浮く → 表面が平滑 → **鏡面反射 (光沢)**
   - **平織**: 交差が多く凹凸 → **拡散** (マット)
   - **メッシュ / レース / オパール**: 開口がある → **透過**
   - 糸の方向性で**異方性** (見る角度で光り方が変わる) も出る

→ つまり「材料による違い」だけでなく、**組織の構造が見え感を大きく左右する**。素材選びでは繊維名だけでなく**組織**まで見る。

### 3DCG のテクスチャと対応づけると分かりやすい

エンジニア / CG に馴染みがあれば、PBR マテリアルのパラメータに重ねると直感的:

| 3DCG (PBR) のパラメータ | 布で対応するもの |
|----------------------|----------------|
| ベースカラー / アルベド | 染料・顔料の色 ([dyeing-finishing.md](dyeing-finishing.md)) |
| ラフネス (roughness) | 表面の平滑さ。朱子 = 低ラフネス (光沢)、起毛 = 高ラフネス (マット) |
| スペキュラ / メタリック | 糸の光沢、スパッタ金属加工、箔 |
| 透過 / オパシティ (alpha) | 透光率、メッシュやレースの開口 |
| ノーマル / ハイトマップ | 織り組織・シボ・プリーツの凹凸 |
| 異方性 (anisotropy) | 糸の方向に沿った光り方 (朱子・サテンで顕著) |
| サブサーフェス | 薄手の布を通る逆光のやわらかさ |

→ 「布選び = テクスチャ + ノーマル + 透過の設定を物理素材で選ぶこと」と捉えると、エンジニアにとって**見え感の議論が一気に具体的**になる。後加工 ([dyeing-finishing.md](dyeing-finishing.md)) は、この各パラメータを後から触る操作と考えられる。

## 3. 吸音性能 (NRC: Noise Reduction Coefficient)

布が音をどう吸うか。

- **NRC** = 250 / 500 / 1000 / 2000 Hz 平均の吸音率 (0〜1.0)
- 通常の薄布: NRC 0.05〜0.15 (ほぼ吸わない)
- フェルト系厚手: NRC 0.3〜0.7
- 吸音壁面用専用フェルト: NRC 0.85+

**用途**: 会場の残響制御。インスタレーションで音を扱うなら「装飾と吸音を兼ねる布」を選ぶと一石二鳥。

主要メーカー: **Camira (英)**, **Kvadrat (デンマーク)**, **国産: 田島ルーフィング, 川島織物セルコン**。

## 4. 引張強度 / 引裂強度

テンション膜で必須。

- **引張強度 (N/cm or N/3cm)** = 縦横方向に引っ張ったとき何 N で破断するか
- **引裂強度 (N)** = 切れ込みから裂けるときの抵抗

| 用途 | 引張強度の目安 |
|------|---------------|
| 装飾幕 (人が触れない) | 100 N/3cm 以上 |
| テンション膜 (人が触れる) | 500 N/3cm 以上 |
| 屋外大型膜 (Christo 級) | 2000 N/3cm 以上 |

**ハトメ位置の引張**は別計算。大事故防止のため建築構造扱いになる場合あり。

## 5. 難燃性 (Flame Retardancy) / 防炎

**公共空間で公開するなら必須**。素材選定の最初の制約。

### 日本の規制

- **防炎物品** = 消防法に基づく防炎ラベル付きの製品 (劇場・展示会場など特定の場所で使用義務)
- **防炎処理** = 後付けで難燃化する処理 (薬剤含浸、コーティング)
- **難燃 1 級〜5 級** = JIS L 1091 による分類 (1 が最も難燃)

### 国際規格

- **NFPA 701** (米国、舞台幕)
- **EN 13501-1** (欧州、建材防火)
- **BS 5867 Part 2** (英国、カーテン)
- **DIN 4102 B1** (独、建材)

**LT 用一言**: 「防炎ラベルなしの布を会場に持ち込むと最悪当日に止められる」。実務的に最重要。

## 6. 帯電 / 静電気

- **静電気帯電圧 (V)** — 触れた人が感電するレベルかどうか
- **電気抵抗 (Ω/sq or Ω·cm)** — 低いほど帯電しにくい
- **導電糸を織り込んだ素材**は帯電しにくい

電子機器を布で覆う場合や、火気のある会場では帯電防止グレード必須。

## 7. 撥水・耐水

屋外設置 / 飲食併設展示で重要。

- **耐水圧 (mmH₂O)** — 数値が大きいほど水を通さない
- **撥水度** — JIS L 1092 はじき分類 (1〜5 級)
- **シリコンコート / フッ素コート** が後処理として使える

## 8. 耐光性 (Light Fastness)

紫外線による色あせ・劣化。

- **JIS L 0842 耐光堅牢度** 1〜8 級
- 屋外長期設置なら 6 級以上が望ましい
- 染料系より顔料系のほうが色持ちする

## 9. 寸法安定性

熱・湿気で縮む / 伸びる。

- **乾熱収縮率** (%表記) — 130℃ 30 分で何 % 縮むか
- **湿熱収縮率** — 蒸気で何 % 縮むか
- ポリエステルは 1〜3%、コットンは 5%+ 縮むことが多い

大型インスタで「初日の張り具合と翌日でテンションが違う」現象の正体はだいたいこれ。

## 仕様書を読むときのチェックリスト

新素材を発注するときに最低限聞く / 調べる項目:

1. ☐ **目付** (g/m²)
2. ☐ **透光率** (%)
3. ☐ **引張強度** (N/3cm)
4. ☐ **防炎ラベル有無** (会場条件次第で死活)
5. ☐ **耐光堅牢度** (屋外なら)
6. ☐ **収縮率** (テンション設計時)
7. ☐ **最大幅** (シーム継ぎ目を作らない場合の上限)
8. ☐ **MOQ (最小発注量)** — 業務用は数百 m〜数千 m が普通
