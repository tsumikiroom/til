# 繊維の三大分類

ファブリック = 「繊維 (fiber)」を糸にして織る・編む・絡める素材。**繊維の種類で物性 (光・水・熱・電気) がほぼ決まる**ので、まずここから。

## 三大分類

### 1. 天然繊維 (Natural Fibers)

| 繊維 | 主な特性 | インスタ用途の傾向 |
|------|---------|------------------|
| **綿 (Cotton)** | 吸湿性、染色性、安価、燃えやすい | 染色実験、フラッグ、軽量幕。難燃処理が必要 |
| **麻 (Linen / Hemp)** | 強い、粗い質感、ザックリした光透過 | 自然系展示、和の文脈 |
| **絹 (Silk)** | 光沢、しなやか、高価 | 高級空間、繊細な投影面 |
| **羊毛 (Wool)** | 保温、吸音、フェルト化 | 吸音パネル、温かみのある演出 |

**特徴**: 質感が豊か、サステナ訴求しやすい。だが**難燃 / 防炎処理が後付けで必要**になることが多い (公共空間では防炎ラベル必須)。

### 2. 合成繊維 (Synthetic Fibers)

| 繊維 | 主な特性 | インスタ用途の傾向 |
|------|---------|------------------|
| **ポリエステル (PET)** | 強い、低吸水、低価格、難燃グレードあり | **インスタレーション最頻出**。投影幕・テンション膜・大型バナー |
| **ナイロン (Nylon / PA)** | 軽量、強靭、伸びる | 吊り構造の補助、ストッキング系 |
| **アクリル** | 発色、ウールに似た風合い | 着色重視の幕 |
| **ポリプロピレン (PP)** | 軽量、撥水、安価 | 不織布、防塵カバー |
| **ポリ塩化ビニル (PVC)** | 防水、厚手、フィルム化可 | 屋外膜構造、テント、エア構造 |

**特徴**: 物性をコントロールしやすい (難燃 / 帯電防止 / UV カットなど機能を後から付加できる)。インスタレーションの主役。

### 3. 機能性 / ハイテク繊維 (Functional / Technical Fibers)

| 繊維 | 主な特性 | インスタ用途 |
|------|---------|-------------|
| **アラミド (Kevlar, Nomex)** | 高強度、耐熱、難燃 | 耐火構造、高張力 |
| **炭素繊維 (Carbon Fiber)** | 軽量・超高強度・導電性あり | 構造材、特殊効果 |
| **光ファイバー** | 光を通す、点発光 | 「光る布」系作品 |
| **導電糸 (Bekinox, Karl Grimm)** | 電気を通す、刺繍可能 | e-textiles、タッチセンサ、配線そのものを織る |
| **形状記憶 (SMA, Nitinol)** | 熱で形が変わる | 自律変形ファブリック |
| **熱変色 (Thermochromic)** | 温度で色変化 | インタラクティブ表面 |
| **蓄光 / 蛍光** | 暗所で光る | 演出効果、暗室展示 |

**特徴**: ここが**インスタレーションのフロンティア**。普通の生地店では買えず、メーカー直接 / 海外通販 / 研究機関ルートが多い。詳細は [../installation-trends/e-textiles.md](../installation-trends/e-textiles.md) と [../references.md](../references.md)。

## エンジニア視点の選び方フロー

```
1. 屋内 or 屋外 ?
   屋外 → PVC / 防水 PET / アクリルコート
   屋内 → ポリエステル基本

2. 防炎・難燃必要 ?
   公共空間 / 大型イベント → 防炎ラベル付きポリエステル一択
   私的空間 → 天然繊維 OK

3. 光をどう扱う ?
   通したい (透過) → 薄手ポリエステル, シフォン, トリコット
   反射させたい → 起毛ポリエステル, スエード調
   通しつつ反射 → ハーフミラー系 (専用素材)

4. 触らせる ?
   触れる → 摩耗耐性 (ナイロン, 厚手ポリ)
   触れない → 何でもよい

5. 動かす ?
   動的 → 軽量 (シルキー系ポリ、シフォン、不織布)
   静的 → 自重に耐える厚手
```

## 「布の手触りの言語化」

エンジニア向けに数値で語れない領域。LT で 1 枚使う価値あり。

- **ハリ (stiffness)** = 縦方向の硬さ。シャツ vs ガーゼ
- **ドレープ (drape)** = 垂れたときの形。柔らかい = 美しいドレープ
- **コシ (resilience)** = 戻る力。シワになりにくい
- **ぬめり (slipperiness)** = 滑らかさ。シルクは「ぬめる」
- **シャリ感** = 涼しげで硬めの触感 (麻、サマースーツ)

カタログ用語として知っておくと素材選びの会話が早い。
