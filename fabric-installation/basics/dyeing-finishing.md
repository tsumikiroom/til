# 染・プリント・後加工

繊維 ([fiber-types.md](fiber-types.md)) と組織 ([weaving-knitting.md](weaving-knitting.md)) が決まったあと、**色を入れる (染・プリント)** と **表面に機能や表情を足す (後加工)** で布の最終的な見え感が決まる。インスタレーションでは「素材そのもの」だけでなく、この**加工の選択**が表現を大きく左右する。

## 1. 染 (Dyeing)

### どの段階で染めるか

| 方式 | タイミング | 特徴 | 例 |
|------|-----------|------|-----|
| **先染め (糸染め)** | 糸の段階で染めてから織る | 色が深い、織り柄で多色 (ストライプ・チェック) を作れる、色落ちしにくい | デニム、ギンガム、シャンブレー |
| **後染め (反染め / 製品染め)** | 織り / 編み / 縫製の**後**にまとめて染める | 安価・短納期、無地向き、ロットで色を揃えやすい | 無地幕、染色実験 |

→ インスタレーションで「グラデーションや特定色を正確に出したい」なら後染めや特注、「織り柄で色を構成したい」なら糸染め。

### 染料と顔料の違い (重要)

| | 染料 (Dye) | 顔料 (Pigment) |
|--|-----------|---------------|
| 着き方 | 繊維の中に**化学的に染み込む** | 表面に**樹脂で接着**する |
| 風合い | 柔らかいまま、発色が鮮やか | やや硬くなる、マット |
| 耐光性 | 種類により弱いことも | 一般に**色持ちが良い** ([physical-properties.md](physical-properties.md) の耐光堅牢度) |
| 繊維との相性 | 繊維ごとに専用染料が必要 | 繊維を選ばない |

**繊維ごとの代表染料**: 綿・麻 → 反応染料 / 直接染料、ポリエステル → 分散染料 (高温で染める)、ウール・絹 → 酸性染料、インディゴ (デニム) → 還元 (建て) 染料。

→ 「**何の繊維か**」で使える染料が決まる。混紡布を 1 色に染めるのが難しいのはこのため (逆にこれを利用したのがオパール加工、後述)。

## 2. プリント (Printing)

布の上に**柄を載せる**手法。全面均一の染と違い、図像をコントロールできる。

| 手法 | 概要 | 向き |
|------|------|------|
| **スクリーンプリント** | 版を使って色ごとに刷る | 大量・ベタ・鮮やかな色面 |
| **インクジェット (デジタルプリント)** | 布に直接インク噴射 | 写真・グラデ・小ロット・複雑な図柄 |
| **昇華転写 (昇華プリント)** | 紙に刷った染料を熱でガス化しポリエステルに転写 | 大判幕・バナー (発色が良く色落ちしにくい) |
| **転写プリント (顔料系)** | フィルムの図柄を熱圧着 | 小ロット・素材を選ばない |

→ 大型の投影バナーや装飾幕は**昇華転写**が定番 (ポリエステル前提)。展示用の一点物なら**インクジェット**で写真調も可能。

## 3. 後加工での機能性追加 (Finishing)

織り / 編みのあと、布の表面に処理を施して**機能や表情**を足す工程。インスタレーションでは「同じ生地が別物に見える / 別の振る舞いをする」決め手になる。

| 加工 | 何をするか | 効果・見え感 | インスタでの使いどころ |
|------|-----------|-------------|----------------------|
| **難燃 / 防炎** | 防炎薬剤を含浸・コーティング | 燃え広がりにくい | 公共空間で必須 ([physical-properties.md](physical-properties.md) 難燃の項) |
| **超撥水** | フッ素 / シリコン樹脂、微細凹凸でロータス効果 | 水滴が玉になって転がる | 水・霧の演出、触感の意外性 (原研哉の作例) |
| **起毛** | 針布で表面を掻いて毛羽立たせる | マットで柔らかい、光を強く拡散 | 反射を抑えた投影面、温かい質感 |
| **スパッタリング (金属塗布)** | 真空中で金属を薄膜状に蒸着 | 金属光沢・反射・導電性 | 鏡面的な反射、ライト映え、e-textile 配線 |
| **オパール加工 (オパールプリント / バーンアウト)** | 混紡布の片方の繊維を薬剤で部分的に溶かす | 溶けた部分が**透ける**模様 | 透過と不透過のパターン、奥行き演出 |
| **ケミカルレース** | 水溶性の土台布に刺繍し、土台を溶かす | 糸だけが残った**レース状** | 繊細な透かし、影絵的演出 |
| **箔プリント** | 接着剤を印刷し金属箔を熱転写 | メタリックな図柄 | 反射のアクセント、スポット強調 |
| **フロッキープリント (植毛)** | 接着剤に短繊維を静電気で立てて植える | ベルベット状の起毛模様 | 触感のコントラスト、光を吸う黒 |
| **熱プリーツ加工** | 熱可塑性繊維 (ポリエステル等) を折って熱セット | 恒久的なプリーツ・シボ | 立体的な陰影、動きの表情 (三宅一生のプリーツが代表) |

### 後加工を選ぶときの視点

- **光をどうしたいか**: 反射を抑えたい → 起毛 / フロッキー、反射を足したい → スパッタ / 箔、透けさせたい → オパール / ケミカルレース
- **触感をどうしたいか**: 撥水でツルッと、フロッキーでフワッと、プリーツで凹凸
- **安全要件**: 公共空間なら難燃は前提。後加工同士で相性 (難燃 + 撥水の両立可否など) を要確認

→ 「見え感」の観点での整理は [physical-properties.md](physical-properties.md) の反射・拡散・透過の節と合わせて読む。
