# 織り・編み・不織布

同じ繊維でも**糸の組み方**で挙動が全然違う。インスタレーション用途では「光の通し方」「伸縮」「エッジ処理」がここで決まる。

## 糸になるまで (紡績)

布の前にまず**糸**。繊維 (fiber) を引き伸ばして撚りをかけ、連続した糸 (yarn) にする工程が**紡績 (spinning)**。

- **撚りの強さ**で風合いが変わる: 強撚 = シャリ感・コシ (例: 楊柳、ジョーゼット)、甘撚 = ふっくら柔らか
- **番手 / デニール**で太さを表す: 細い糸ほど薄く繊細な布になる
- **フィラメント糸** (長い 1 本: 絹・合成繊維) は滑らかで光沢、**紡績糸 / スパン糸** (短繊維を撚る: 綿・麻・ウール) は毛羽があり光を拡散する

→ この「糸の表面状態 (光沢かマットか)」が後の**見え感**に効く。詳細は [physical-properties.md](physical-properties.md)。

## 4 つの基本構造

### 1. 織物 (Woven)

経糸 (たていと) と緯糸 (よこいと) が直交。安定していて伸びない。エッジを切ると糸がほつれる (要 縁始末)。

**三大織り組織:**

| 種類 | 構造 | 特徴 | インスタ用途例 |
|------|------|------|---------------|
| **平織 (Plain)** | 1 本ずつ交差 | 強い、表裏同じ、シンプル | 投影スクリーン、フラッグ |
| **綾織 (Twill)** | 斜めの線が出る | しなやか、厚手にしやすい | デニム調、テンション膜 |
| **朱子織 (Satin)** | 経糸が長く浮く | 光沢、ぬめり | 光沢演出、ホログラフィック演出 |

**密度の指標:**
- **打込本数** (糸/inch or cm) — 高いほど目が詰まる
- **目付** (g/m²) — 1 m² あたりの重さ。30 g (ガーゼ) 〜 300 g (キャンバス)
- **デニール (D)** — 糸の太さ。低いほど細い (シフォンは 30D 程度、テント生地は 1000D 超)

### 2. 編物 (Knit / Knitted)

糸がループ状に絡む。**伸縮する**。エッジを切ってもほつれにくいが伝線する場合あり。

| 種類 | 特徴 | 用途 |
|------|------|------|
| **トリコット (Tricot)** | 縦編み、適度な伸縮 | ストレッチ膜、人体ラッピング、ステージ |
| **ジャージー (Jersey)** | 横編み、よく伸びる | コスチューム、有機的形状 |
| **ラッセル (Russell)** | 編み目を変えてレース調にできる | 装飾的な透過素材 |
| **ダブルラッセル / メッシュ** | 中空、空気を通す | 半透明スクリーン、立体感ある投影面 |

**インスタレーション用途**:
- 伸縮するので**複雑な形に張れる** (球体、ねじれ形状、人型)
- ストレッチ膜は**プロジェクションマッピング**でよく使う (Lycra / spandex)

### 3. 不織布 (Nonwoven)

繊維をランダムに絡めてシート化。織らない、編まない。**安価で大面積、エッジが切りっぱなしで OK**。

| 種類 | 製法 | 用途 |
|------|------|------|
| **フェルト (Felt)** | 圧縮 / 縮絨 | 吸音、装飾、温かい質感 |
| **スパンボンド (Spunbond)** | 溶融紡糸 + 接着 | 防塵カバー、簡易幕、不織布バッグ |
| **ニードルパンチ** | 針で絡める | 厚手フェルト、自動車内装 |
| **メルトブロー** | 極細繊維、フィルター用 | マスク、エアフィルター |

**インスタレーション用途**:
- 大量に安価で必要なとき (使い捨て幕、空間を埋める)
- **フェルト吸音**: 視覚 + 音響演出を同時にやれる
- 「紙のようでもあり布のようでもある」中間素材

### 4. ネット / メッシュ (Net / Mesh)

開口率が高い (目が大きい)。光・空気・音をかなり通す。

| 種類 | 特徴 | 用途 |
|------|------|------|
| **養生ネット** | PE/PP 樹脂、頑丈、防炎品あり | 大型構造物の包み込み |
| **チュール** | 細糸の網、装飾的 | 衣装、ベール |
| **3D メッシュ** | 厚みがある中空編み | 立体感のある膜 |

**インスタレーション用途**:
- **ハーフトーン投影**: ネットに投影すると向こうも透けて見える (空間感)
- **覆い隠す / 隔てる**: 完全に遮らず存在を感じさせる

## 光の通し方で並べると

```
通す ←――――――――――――――――――――→ 通さない
チュール  メッシュ  シフォン  オーガンザ  平織  サテン  不織布厚手  キャンバス
```

中間域 (シフォン、オーガンザ、薄手平織) が**投影面として最も使い勝手が良い**。光を散乱しつつ少し通すので、両面投影や奥行き感が出る。

## 織りの道具とジャガード (コンピュータとの親和性)

織機は経糸を上下に開いて (開口)、そこへ緯糸を通すことの繰り返し。経糸を上下させる部品が**綜絖 (そうこう / heddle)**。どの綜絖を上げるかのパターンが組織を決める。

- **平織・綾織・朱子**程度の単純な組織は、数枚の綜絖をまとめて上下する**ドビー織機**で織れる
- **複雑な紋様 (絵柄・大柄)** を織るには、経糸を**1 本ずつ独立に**上下させたい → ここで**ジャガード**

### ジャガード織機

19 世紀初頭に Joseph-Marie Jacquard が実用化。**パンチカードの穴のオン / オフ**で、各経糸 (に繋がる綜絖) を上げるか上げないかを 1 本単位で選択する。

- 穴あり = その経糸を上げる / 穴なし = 上げない、という**2 値の制御**
- カードを 1 枚送るごとに緯糸 1 段ぶんの上下パターンが決まる → カードを綴じた長い列で 1 枚の紋様を織る
- この「穴のオン / オフで動作を記述する」発想は、後の**計算機 (Babbage の解析機関、Hollerith のパンチカード)** に影響したとされる。つまり**ジャガードは本質的にコンピュータと親和性が高い**

### コンピュータジャガード (電子ジャガード)

物理カードの代わりに**電子データ**で各経糸の上下を制御する現代の織機。

- 紋様を画像 / データとして編集し、そのまま織りに落とせる
- 1 本ずつ制御できるので、**写真のような階調表現**や複雑なテクスチャ織りが可能
- 代表例: TextielLab (オランダ) などで使われる **TC2 ループ (Digital Jacquard loom)**。アーティストがデータを持ち込んで織れる制作環境

→ インスタレーション文脈では「**画像データ = 織り組織**」として扱える点が面白い。3DCG / ジェネラティブの出力を物理的な布に変換する回路になりうる。

## 工程の全体像 — デニムができるまで

1 枚の布は複数工程の積み重ね。代表例として**デニム**で通して見る。

```
綿 → 紡績 → 糸染め(インディゴ) → 綾織 → ウェザリング(後加工)
```

1. **紡績**: 綿を糸にする (経糸・緯糸ぶん)
2. **糸染め**: 経糸だけを**インディゴ**で染める。インディゴは水に溶けないので、還元して溶かし → 繊維に浸し → 空気で**酸化させて発色・定着**。何度も浸けて濃くする。緯糸は染めず白のまま
3. **綾織 (twill)**: 染めた経糸 × 白い緯糸を綾織に。表に経糸 (青) が多く出る → **表が青・裏が白**になる
4. **ウェザリング (後加工)**: ストーンウォッシュ・ダメージ加工などで色落ち / 表情を作る

→ 「**どの段階で色を入れるか (糸染め vs 後染め)**」「**どの組織で織るか**」「**仕上げに何を足すか**」の組み合わせで最終的な見え方が決まる。染と後加工は [dyeing-finishing.md](dyeing-finishing.md) に分けて整理。

## エッジ処理 (これを忘れると現場で詰む)

- **織物**: ほつれる。**縁巻き縫い (オーバーロック)** か **熱カット (合成繊維のみ)** が必要
- **編物**: 伝線する可能性あり。**ロックミシン** or **接着テープ**
- **不織布**: そのまま切りっぱなしで OK
- **PVC 系**: 熱で溶かして閉じる (高周波溶着 / ホットエア)

LT で「エッジ処理を忘れて初日でほつれた」みたいなあるある話を入れると刺さる。
