# ファブリックを特徴づける変数 (一覧)

布の見え方・触り方・振る舞いは、いくつもの**変数の組み合わせ**で決まる。ここでは「どんな軸があるか」をバーっと並べた早見表。詳細は各ページへ。

布は **材料 → 糸 → 組織 → 色柄 → 後加工** と作られ、その結果として **物性・見え感・風合い** が現れる。変数もこの順で整理すると見通しが良い。

```
[繊維] → [糸] → [組織] → [染・プリント] → [後加工]  ──→  物性 / 見え感 / 風合い
```

## 1. 繊維 (材料) の変数

| 変数 | 取りうる値・レンジ | 効くところ |
|------|-----------------|-----------|
| 繊維の種類 | 天然 (綿・麻・絹・羊毛) / 合成 (PET・ナイロン・PVC) / 機能性 (導電・光ファイバ・形状記憶) | 物性のベース (光・水・熱・電気) |
| 長さ | 長繊維 (フィラメント) / 短繊維 (ステープル) | 光沢か毛羽か、強さ |
| 断面形状 | 丸 / 異形 (三角・中空など) | 光沢・吸水・軽さ |
| 繊維固有の性質 | 光沢・吸湿性・比重・融点・燃えやすさ | 後工程の制約 (染料・難燃) |

→ 詳細: [fiber-types.md](fiber-types.md)

## 2. 糸 (紡績) の変数

| 変数 | 取りうる値・レンジ | 効くところ |
|------|-----------------|-----------|
| 太さ | 番手 / デニール (D) / テックス | 薄さ・透け・重さ |
| 撚りの強さ | 甘撚 〜 強撚 | ふっくら / シャリ感・コシ |
| 撚りの方向 | S 撚り / Z 撚り | 風合い・柄効果 |
| 構成 | 単糸 / 双糸 (合撚) / 加工糸 | 強さ・かさ高さ |
| 糸の状態 | フィラメント / スパン (紡績) | 光沢 (反射) か拡散か |
| 混紡 | 単一 / 混紡比率 (例 ポリ65/綿35) | 染まり方・風合い・コスト |

→ 詳細: [weaving-knitting.md](weaving-knitting.md) (紡績の節)

## 3. 組織 (構造) の変数

| 変数 | 取りうる値・レンジ | 効くところ |
|------|-----------------|-----------|
| 構造の種類 | 織 / 編 (ニット) / 不織布 / ネット・メッシュ | 伸縮・ほつれ・透け |
| 織り組織 | 平織 / 綾織 / 朱子織 / ジャガード (紋織) | 光沢・しなやかさ・柄 |
| 密度 | 打込本数 (本/inch) | 目の詰まり・透け |
| 目付 | g/m² (30 ガーゼ 〜 300+ キャンバス) | 軽さ・厚み・強さ |
| 開口率 | 詰まった〜メッシュ状 | 透光・通気・透け |
| 伸縮性 | 織=ほぼ無 / ニット=大 | 立体への張り |
| 厚み | 薄手 〜 厚手・中空 (3D メッシュ) | 立体感・吸音 |

→ 詳細: [weaving-knitting.md](weaving-knitting.md)

## 4. 色・柄 (染・プリント) の変数

| 変数 | 取りうる値・レンジ | 効くところ |
|------|-----------------|-----------|
| 着色剤 | 染料 (染み込む) / 顔料 (表面接着) | 風合い・発色・耐光性 |
| 染めの段階 | 先染め (糸染め) / 後染め (反染め) | 多色織り柄か無地か、色落ち |
| 柄の付け方 | 無地 / 織り柄 / プリント柄 | 図像のコントロール度 |
| プリント手法 | スクリーン / インクジェット / 昇華転写 | ロット・写真調・色持ち |

→ 詳細: [dyeing-finishing.md](dyeing-finishing.md)

## 5. 後加工 (仕上げ) の変数

| 変数 | 取りうる値・レンジ | 効くところ |
|------|-----------------|-----------|
| 機能加工 | 難燃 / 撥水 / 帯電防止 / UV カット など | 安全要件・屋外耐性 |
| 表面加工 | 起毛 / 金属蒸着 / 箔 / フロッキー | 反射・触感 |
| 透かし加工 | オパール (溶かす) / ケミカルレース | 透過の柄 |
| 形態加工 | 熱プリーツ / シボ加工 | 凹凸・陰影・動き |

→ 詳細: [dyeing-finishing.md](dyeing-finishing.md)

## 6. 結果として現れる変数 (物性・見え感・風合い)

上の 1〜5 の積み重ねが、最終的にこう現れる。素材選定で**実際に測る / 仕様書で見る**のはここ。

### 物性 (数値で語れる)

| 変数 | 単位・指標 |
|------|-----------|
| 透光率 | % |
| 反射 / 拡散 | ゲイン、拡散度 |
| 引張・引裂強度 | N/3cm, N |
| 吸音 | NRC (0〜1.0) |
| 難燃 / 防炎 | 防炎ラベル、難燃級 |
| 撥水・耐水 | 撥水度、耐水圧 |
| 耐光性 | 堅牢度 1〜8 級 |
| 寸法安定性 | 収縮率 % |

→ 詳細: [physical-properties.md](physical-properties.md)

### 見え感 (反射・拡散・透過の配分)

光が **反射 / 拡散 / 透過** にどう分かれるか。組織と材料で決まる。3DCG の PBR (ラフネス・スペキュラ・透過・ノーマル・異方性) に対応づけると掴みやすい。

→ 詳細: [physical-properties.md](physical-properties.md) の「見え感を理解する」

### 風合い (手触り・言語化しにくい変数)

| 変数 | 意味 |
|------|------|
| ハリ (stiffness) | 縦方向の硬さ |
| ドレープ (drape) | 垂れたときの形の美しさ |
| コシ (resilience) | 戻る力・シワになりにくさ |
| ぬめり | 滑らかさ (絹) |
| シャリ感 | 涼しげで硬めの触感 (麻・強撚) |

→ 詳細: [fiber-types.md](fiber-types.md) の「布の手触りの言語化」

## まとめ — 変数の効き方の勘所

- **物性のベースは「繊維」**、でも**見え感を大きく動かすのは「組織」**
- **色は「染料 / 顔料」と「先染め / 後染め」の 2 軸**でだいたい説明できる
- **後加工は最終調整**: 物性 (難燃・撥水) も見え感 (起毛・箔・オパール) も後から足せる
- インスタレーションでは「繊維名」だけで素材を語らず、**組織・加工まで**指定すると意図が伝わる
