# 企画への橋渡し

エンジニア視点で集めた素材知識を、**インスタレーション企画の言語**に翻訳するためのメモ。

## なぜファブリックを選ぶか (企画書で書ける理由)

硬質素材ではなく布を選ぶ判断は、必ず**何かしらのコンセプト**と繋がっているはず。

### 1. 光の媒介

- **透過 / 半透過 / 反射** を**素材自体で調整**できる
- 硬い壁では出せない**多層・奥行き・空中**の演出が可能
- 関連: [installation-trends/projection-surface.md](installation-trends/projection-surface.md)

### 2. 空気との対話

- **動く・揺れる・呼吸する**素材
- 環境の気配 (風、湿度、人の動き) を可視化できる
- 関連: [installation-trends/kinetic-fabric.md](installation-trends/kinetic-fabric.md)

### 3. 身体性

- 触れる、抱える、潜る、纏う
- 人間の生活素材 (服、寝具) と連続性があり**距離が近い**
- 関連: Numen "String Installations", Behnaz Farahi の作品

### 4. スケーラビリティ

- 大きく作っても**軽い / 畳める / 運べる**
- 屋外イベント / 巡回展示に強い
- 関連: Christo, Echelman の都市スケール作品

### 5. サステナビリティ訴求

- 天然繊維 / リサイクル素材を選べる
- 撤収後の再利用も計画可
- 但し合成繊維はマイクロプラスチック問題あり (両刃の剣)

## 「なぜ今ファブリックなのか」 — 文脈の作り方

LT で 1〜2 枚使って良い「なぜ今」の引き合い:

- **デジタルからの揺り戻し**: 高精細 LED の時代だからこそ**揺らぎ・偶然・有機性**が求められる
- **サステナ意識**: 軽量で運搬・廃棄負荷が低い素材への関心
- **AI × 素材**: AI 生成映像の投影面、e-textile の制御に AI、素材 × AI のフロンティア
- **アンビエント志向**: 短時間で消費する刺激より、**長時間滞在型・没入型**の演出が求められる時代
- **触覚回帰**: 画面 (硬い表面) からの離脱、触れる体験への関心

## どの段階で素材を決めるか

企画と素材の関係は二通りある。

### A. コンセプト → 素材 (Top-down)

「アンビエント / 呼吸 / 記憶」のコンセプト先行、後から素材を探す。

- 利点: 強い表現意図に素材を従わせられる
- 欠点: 物性的に無理な要求になりがち (「軽く・大きく・防炎」の三立)

### B. 素材 → コンセプト (Bottom-up)

「面白い素材を見つけた」が起点、その素材で何ができるか考える。

- 利点: 物性に無理がない、技術的優位性が出やすい
- 欠点: 概念が後追いになりがち、説明が弱くなる

**実務的にはハイブリッド**: 初期は A、後半は B を行き来する。エンジニアは B が得意。

## 物性 → 用途のマッピング

| やりたいこと | 着目すべき物性 | 候補素材 |
|------------|---------------|---------|
| 投影面にしたい | 透光率、ゲイン | 専用リアプロ生地、白ポリエステル |
| 動かしたい | 軽さ (目付)、コシ | シフォン、薄手不織布 |
| 巨大化したい | 引張強度、最大幅 | PVC コート、テント生地 |
| 触れさせたい | 摩耗、難燃、安全性 | 厚手ポリエステル、フェルト |
| 吸音したい | NRC | 厚手フェルト、Kvadrat 系 |
| 発光させたい | 導電性、編み構造 | 導電糸 + LED、光ファイバ織り |
| 自然分解させたい | 繊維種 | 麻、綿 |

詳細は [basics/physical-properties.md](basics/physical-properties.md) と [basics/fiber-types.md](basics/fiber-types.md) を参照。

## コスト・搬入・廃棄の現実

企画段階で見落としやすい現実的論点。

### コスト

- **素材費**: m² 単価で 500 円 〜 数万円
- **加工費**: 縫製、ハトメ打ち、難燃処理は別途
- **構造費**: フレーム、吊り金具、モーターなど
- **MOQ**: 業務用素材は最小 100 m〜 が普通

### 搬入

- **巻物で運ぶ**: 6m 幅の布を巻物にすると直径 30cm〜
- **会場サイズ**: 折り畳んだサイズ < 搬入口
- **エレベーター制約**: 高層展示は要注意

### 廃棄

- **合成繊維**: マイクロプラスチック問題、産廃扱い
- **天然繊維**: コンポスト可能
- **e-textile**: 電子廃棄物処理が必要

**サステナ訴求 = リユース計画必須**: 撤収後に別作品で使う / リサイクルパートナー確保 / 鑑賞者に配布、など事前設計。

## エンジニアが企画に持ち込める価値

技術者として企画議論に入るときの差別化ポイント:

1. **物性で確からしさを保証** — 「これは本当に張れる」「これは触っても危なくない」
2. **コスト概算** — 素材費 + 加工費 + 構造費を素早く見積もれる
3. **制御 / インタラクション設計** — センサ / アクチュエータの実装可否を早期判断
4. **失敗パターンを知っている** — 撓み、たるみ、共振、断線などの予見
5. **新素材の情報** — 業界外から見つけてくる導電糸 / 形状記憶 / 機能性繊維

これらが**「アーティスト発想 + エンジニア発想」の協業**で他にないインスタレーションを作る可能性を開く。
