# Kinetic Fabric (動く布)

布の柔らかさを活かして「動く」ことを主役にしたインスタレーション。風・ファン・モーター・空気圧・形状記憶など、駆動源は多様。

## なぜ「動く」のか

布は**自重で揺れる、わずかな空気で動く**。硬質素材では再現困難な「儚さ・呼吸感・有機性」が出る。

→ アンビエント / 環境的演出と相性が良い。鑑賞者が**じっと見続けられる**作品になりやすい。

## 駆動方式の分類

### 1. 自然風 (Natural Wind)

屋外設置、風で動く。最も単純で最も予測困難。

- **Christo & Jeanne-Claude** "The Gates" (2005) — 風で揺れる橙色幕門 7,500 個
- **Christo** "The Pont Neuf Wrapped" (1985) — 橋を布で包む
- 屋外規模に耐える物性 (引張、撥水、耐光) が必要

### 2. ファン送風 (Fan-driven)

サーキュレーター / ダクトファンで人工的に風を送る。再現性高い。

- **Studio Drift** "Drifters" / "Fragile Future" — 浮遊する/揺れる軽量素材
- 風量制御 = 動きの制御。**インバーター制御**で滑らかに変化
- 注意: ファンの動作音、空気圧で位置がずれる

### 3. モーター / プーリー (Motor-driven)

布の一部にワイヤーを繋ぎ、モーターで引く / 緩める。

- **United Visual Artists (UVA)** "Volume" (2006) — 動く光柱、布ではないが類似機構
- **rAndom International** 各種作品 — モーター制御の精密な動き
- ロボティクス的アプローチ。プログラマブル

主な機構:
- **DC モーター + プーリー** → 上下動
- **サーボモーター** → 細かい角度制御
- **ステッパーモーター** → 位置精密
- **リニアアクチュエーター** → 直線運動

### 4. 空気圧 / 油圧 (Pneumatic / Hydraulic)

エア袋を布で覆って膨らます / 縮める。または布自体に空気層を持たせる。

- **Smarin** など — エア構造を伴う家具/インスタ
- **Inflatable architecture** 分野 — 巨大バルーン構造
- 利点: 大型でも軽量
- 注意: コンプレッサーの音、空気漏れ

### 5. 形状記憶 (Shape Memory Alloy)

ニチノール (Nitinol) などの形状記憶合金を糸として織り込む。**通電で形状変化**。

- **Hyo Yeol Kim** "Bio-Logic"
- **Behnaz Farahi** "Caress of the Gaze" — 視線追跡で動くファブリックウェア
- 利点: モーターレスで動く、静音
- 注意: 反応速度遅い、繰り返しで疲労

### 6. 静電気 / 磁気

電気的引力で布を動かす実験的手法。研究段階。

## 動きのデザイン

「ただ動かす」では退屈。**動きのリズムとパターン**が作品の質を決める。

### パターン例

- **呼吸**: ゆっくり膨らんで縮む。生物感
- **波**: 隣接ユニットが位相をずらして動く
- **振動**: 細かく震える。緊張感
- **ランダム**: 予測できない、自然の揺らぎ
- **インタラクション**: 鑑賞者の動き / 音 / 心拍に応答

### 制御設計

```
[センサ入力] → [マイコン / PC] → [モーター / バルブ] → [布]
                    ↑
            [マッピング・スムージング]
```

スムージング (Lag / 補間) が滑らかさの鍵。急に動かすと安っぽい。

## 安全マージン

動的ファブリックは**観客を傷つけないこと**が最優先。

- 風: 観客の目に砂塵が入らない速度に抑える
- モーター: 巻き込み防止のガード
- 空気圧: 急減圧時の鞭打ち防止
- 高所設置: 落下防止のセーフティワイヤー (二重化)
- センサ: 観客検知でフェイルセーフ停止

## TouchDesigner / 制御ソフトとの連携

- **TouchDesigner**: センサ入力 + モーター制御 (DMX / Arduino 経由)
- **DMX 512** — 照明 / モーター制御の業界標準プロトコル
- **Arduino + Servo / Stepper Library** — 小規模実装
- **GRBL** — ステッパーモーター制御 (CNC ベース)
- **OSC** — ネットワーク経由でマルチデバイス制御
