# 投影面としてのファブリック

プロジェクションマッピングの投影先として布を使う。**硬い壁とは違う独自の表現**ができる。

既存ノート [../../projection-mapping/references.md](../../projection-mapping/references.md) のプロジェクションマッピング 6 分類と組み合わせて読む。

## なぜ布に投影するか (硬い壁との違い)

| 観点 | 硬い壁 | ファブリック |
|------|--------|------------|
| 表面の凹凸 | 整える必要あり | 自由に変形可 |
| 光の透過 | 完全反射のみ | 透過 / 半透過の表現可 |
| 形 | 固定 | テンションで自在 |
| 動き | 静的 | 風 / ファンで動く |
| 設置・撤収 | 重い | 軽い・畳める |

→ ファブリックは**空中・複雑形状・動的・複数面**といった硬い壁ではできない投影が可能。

## 投影の 3 方式

### 1. フロントプロジェクション (Front Projection)

観客と同じ側から投影。最も一般的。

- **反射型素材**を使う: ホワイト系ポリエステル、起毛系
- ゲイン 1.0〜1.5 で**明るさ確保**
- プロジェクターの台数 1 台で済む
- **観客の影が映る問題**あり

### 2. リアプロジェクション (Rear Projection)

布の裏側から投影、観客は表側から透けてくる像を見る。

- **半透過素材**: シフォン、薄手ポリ、専用リアプロ生地
- **メリット**: 観客の影が映らない、布の前後の空間演出
- **デメリット**: プロジェクター用の裏スペースが必要、明るさ確保が難しい
- 透過率の目安: **30〜50%** が使いやすい

**製品例**: 「Gauze-screen」「Holo-screen」など (映像演出向け透過スクリーン素材)。

### 3. 両面投影 / クロスプロジェクション

両側からそれぞれ別の映像を出す。

- 半透過素材で**前後で異なる映像**が見える
- 角度を変えると別の像が浮かぶ「ホログラフィック効果」
- 演出が強力だがキャリブレーションが難しい

## 素材別の特性

| 素材 | 透光率 | 反射特性 | 適性 |
|------|--------|---------|------|
| **白ポリエステル平織** | 5〜15% | 拡散反射 | フロント投影標準 |
| **薄手シフォン** | 50〜70% | 半透過 | リアプロ、空中演出 |
| **ストレッチトリコット (Lycra)** | 0〜30% | 拡散反射、伸縮 | 立体形状への投影 |
| **メッシュ / ネット** | 50〜90% | 線状の像 | 多層投影、奥行き演出 |
| **不織布 (専用品)** | 10〜30% | やや拡散強 | 仮設展示 |
| **シルバー / メタリック** | 0〜10% | 鏡面反射 | スポット強調、特殊効果 |
| **ホログラフィック生地** | 角度依存 | 角度で像が変わる | 高級空間、特殊演出 |

## 多層・空中投影のテクニック

1. **複数の薄幕を奥行き方向に並べる** → 観客視線で奥行き感のある立体映像 (3D 風)
2. **半透過幕 + 後方のオブジェクト** → 物体が「現れる / 消える」演出 (Pepper's Ghost の派生)
3. **動く布への投影** → 風で揺れる布に映像、ズレ / 歪みが詩的に見える
4. **複数面同時投影** → 1 つの巨大幕を複数プロジェクターで分担 (エッジブレンディング)

## マッピング時の注意

- **テンションのムラ → 投影像が歪む**: 事前にキャリブレーション必須 (MadMapper, Resolume, Notch などのソフトでマスク・歪み補正)
- **布の動き → リアルタイム追従**: 静止前提で組むのが基本。動きを使いたいなら**動きを内包したコンテンツ**を作る (固定マッピングで揺らぎ自体を演出に)
- **照明とのコンフリクト**: 会場の照明が反射すると投影が薄まる。会場光を落とせる前提で

## TouchDesigner / Notch との連携

ファブリック投影は**毎フレームの調整が必要**になりがち。プロのインスタレーション現場では:

- **TouchDesigner**: マッピング、リアルタイム調整、センサ連携
- **Notch**: VJ / ライブイベント向けのリッチコンテンツ
- **Resolume Arena**: VJ / マルチプロジェクター運用
- **MadMapper**: 簡易マッピング

詳細は [../../audio-reactive/fft-audio-reactive-touchdesigner.md](../../audio-reactive/fft-audio-reactive-touchdesigner.md) などの TouchDesigner ノートを参照。

## 代表作 / 事例

- **Bot & Dolly** "Box" (2013) — ロボットアーム + 投影 + 動く幕で空間操作
- **teamLab** 各種作品 — 多層幕への投影、来場者が幕の中を歩く構造
- **Refik Anadol** "Machine Hallucinations" — 大型幕全面に AI 生成映像
- **d'strict** "Wave" — 巨大 LED + 半透明素材で錯視的体験
