# 代表作品 / 事例集

LT で「事例として 5〜8 件挙げる」用のリスト。素材・構造・効果の 3 軸で並べる。

## 作品リスト

### 1. Christo & Jeanne-Claude — "The Gates" (2005)

| 項目 | 内容 |
|------|------|
| 場所 | Central Park, New York |
| 規模 | 7,503 個の鋼鉄ゲート、橙色布、計 37 km |
| 素材 | 防炎ナイロン布、サフラン色 |
| 構造 | 5m 弱の鋼鉄門 + 布パネル |
| 駆動 | 自然風 |
| 効果 | 公園全体が「橙色の川」に。儀礼的・荘厳 |

ファブリックが**空間規模**に達した代表例。**都市スケールの儀式化**。

### 2. 塩田千春 — "The Key in the Hand" (2015)

| 項目 | 内容 |
|------|------|
| 場所 | ヴェネツィア・ビエンナーレ 日本館 |
| 規模 | 50,000 個の鍵を赤い糸で吊る |
| 素材 | 赤い毛糸 (テキスタイル素材として) |
| 構造 | 天井から無数の糸を垂下 |
| 駆動 | 静的 |
| 効果 | 「記憶 / 個人史」のメタファー。糸の密度が空間を侵食 |

**糸 (=ファブリックの最小単位) を空間構造化**した極限例。日本人作家として国際評価が高い。

### 3. teamLab — "Forest of Resonating Lamps" (2016〜)

| 項目 | 内容 |
|------|------|
| 場所 | チームラボ ボーダレス / プラネッツ 等 |
| 規模 | 数百個のランプを天井から吊り下げ |
| 素材 | ガラスランプ + 反射素材 / 鏡面壁 (ファブリックは間接) |
| 構造 | 静止だが鏡で無限増殖 |
| 駆動 | 来場者の位置検知でランプが連鎖発光 |
| 効果 | アンビエント型インタラクション |

直接的なファブリック作品ではないが、**「素材 + センサ + 群衆」という構造**が参考になる。teamLab の他作品 (例えば作品内に布を歩いて潜る系) も参照。

### 4. United Visual Artists (UVA) — "Volume" (2006)

| 項目 | 内容 |
|------|------|
| 場所 | V&A Museum 中庭 等 (巡回) |
| 規模 | 46 本の光柱、来場者が歩き回れる |
| 素材 | 光柱本体は LED + 半透明素材。布主体ではないが布的視覚効果 |
| 構造 | 個別自立 |
| 駆動 | 来場者の動きに反応 (赤外線センサ) |
| 効果 | ミニマル・哲学的、光と音と人の即興的合奏 |

ファブリック作品ではないが、**「軽量・半透過・群衆応答」という美学**がファブリック系と通じる。

### 5. Janet Echelman — "1.78" シリーズ (2010〜)

| 項目 | 内容 |
|------|------|
| 場所 | 各都市の公共空間 (Boston, Singapore, Madrid 等) |
| 規模 | 数百 m に及ぶ空中網彫刻 |
| 素材 | 高強度ポリエチレン (UHMWPE) / Spectra Fiber などのネット |
| 構造 | 吊り構造 (テンション + 自重) |
| 駆動 | 自然風 |
| 効果 | 巨大な「空中のクラゲ」、夜は照明で発光 |

**ネット (メッシュ) を空中構造体に**変えた代表。技術的にも美的にも高い達成。

### 6. Numen / For Use — "String Installations" (2010〜)

| 項目 | 内容 |
|------|------|
| 場所 | 各国巡回 (ウィーン、東京等) |
| 規模 | 数千 m の糸で空間を埋め、人が登れる構造 |
| 素材 | 高強度織糸、テンション張り |
| 構造 | 自立 + 壁固定の組み合わせ |
| 駆動 | 静的 (人が触る・登る) |
| 効果 | 「触れる空間アート」、観客参加型 |

**糸 (テキスタイル原料) で身体スケールの構造体**を作る。インスタレーション + 体験の融合。

### 7. Studio Drift — "Drifters" (2017〜)

| 項目 | 内容 |
|------|------|
| 場所 | Stedelijk Museum 等 |
| 規模 | 数 m サイズの浮遊する軽量物体 |
| 素材 | 軽量複合材 + テキスタイル |
| 構造 | ドローンで浮遊 / ファンで揺らす |
| 駆動 | 動的 (プログラム制御) |
| 効果 | 「コンクリートが浮く」錯視的体験 |

**ファブリック + ロボティクス**のフロンティア。次世代の方向性。

### 8. Refik Anadol — "Machine Hallucinations" (2019〜)

| 項目 | 内容 |
|------|------|
| 場所 | Artechouse 等 |
| 規模 | 大型壁面投影 |
| 素材 | 投影面に半透過素材を使うケース多 |
| 構造 | 投影 |
| 駆動 | AI 生成リアルタイム映像 |
| 効果 | 大規模没入型データビジュアル |

**ファブリック × AI 映像**の現代的代表。素材は投影面として「映像を受ける器」。

### 9. Behnaz Farahi — "Caress of the Gaze" (2015)

| 項目 | 内容 |
|------|------|
| 場所 | ギャラリー展示 / ウェアラブル |
| 規模 | 着用可能なファブリック・ガーメント |
| 素材 | 形状記憶合金 + 3D プリント + テキスタイル |
| 構造 | 着る・動く |
| 駆動 | 視線追跡 (カメラ + ML) で動作 |
| 効果 | 「見られると反応する服」、観察と被観察の反転 |

**身体スケール × 形状記憶 × ML**。e-textile の到達点の 1 つ。

### 10. Hiroshi Yoshimura / 環境音楽家 + 空間 (参考)

直接の作品ではないが、**ファブリック空間における音響演出**の参考として「環境音楽」概念を引用すると LT で深みが出る。吸音ファブリック ([../basics/physical-properties.md](../basics/physical-properties.md) の NRC 項) と組み合わせる発想。

## 手近な使用例 (国内・身近な例)

海外の大規模作品だけでなく、身近に見られる / 国内の例も並べておくと「自分でも触れる素材」という実感が湧く。

### 原研哉 — 超撥水テキスタイル

- グラフィックデザイナー原研哉がディレクションした繊維展示 (Tokyo Fiber "SENSEWARE" 系) で、日本の先端繊維として**超撥水素材**を紹介
- 水を落とすと**水滴が玉のまま転がる**、布の上で水が「乗る」体験
- 後加工 ([../basics/dyeing-finishing.md](../basics/dyeing-finishing.md) の超撥水) が**そのまま表現になっている**例。素材の物性 = コンセプト
- ※ 具体的な展示名・年は要確認

### NOIZ — 大阪・関西万博パビリオン

- 建築 / コンピュテーショナルデザインのスタジオ NOIZ による万博関連のパビリオン
- 布 / 膜素材を構造・スクリーン的に使う方向性 (デジタルファブリケーション × テキスタイル)
- ※ 担当パビリオン名・素材構成・規模など**詳細は要確認**。ユーザー個人メモとして記録、出典を後で補完する

### teamLab ボーダレス — プロジェクション面の工夫

- 硬い壁だけでなく、**柔らかい面・布・空間を仕切る薄い膜**へ投影し、作品が部屋をまたいで連続する構造
- 来場者が面の間を歩く / 触れることで、投影面が「環境」になる
- 投影面の選び方として [projection-surface.md](projection-surface.md) の多層・空中投影と通じる
- ※ 具体作品ごとの投影面素材は要確認

### 大巻伸嗣 — オーガンジーを用いた一連の作品

- "Liminal Air" シリーズなどで、**巨大なオーガンジー (薄い透ける布)** を空気 (送風) で波打たせる
- 透過 + 動き + 光で、布が「空気そのものの可視化」のように見える
- [kinetic-fabric.md](kinetic-fabric.md) (送風で動かす) と [../basics/physical-properties.md](../basics/physical-properties.md) (透過・拡散) の合わせ技

→ これらは「**後加工で物性を作る (原研哉)**」「**膜を構造に使う (NOIZ)**」「**投影面の工夫 (teamLab)**」「**送風 × 透過布 (大巻)**」と、本ノートの各トピックの実例になっている。

## 5 つの分類軸で並べ直すと

| 軸 | 代表作 |
|----|--------|
| **巨大スケール** | Christo, Echelman |
| **微細・繊細** | 塩田千春, Numen |
| **動的・キネティック** | Studio Drift, Farahi |
| **投影・映像** | Refik Anadol, teamLab |
| **観客参加** | UVA, Numen |

LT ではこの 5 つの軸ごとに 1 作品ずつ挙げると整理しやすい。
