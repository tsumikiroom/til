# テンション膜・吊り構造

布を**引っ張って張る**ことで形を作る使い方。インスタレーションの最も基本的かつ大規模化できる手法。

## 基本原理

布は引っ張られて初めて平面 / 曲面として「立つ」。テンション (張力) のかけ方で形状が決まる。

```
[両端固定 → 平面]      [3 点固定 → 双曲面]      [円形フレーム → ドーム / 円錐]
```

主要構造タイプ:

| 構造 | 形状 | 例 |
|------|------|-----|
| **Flat (フラット)** | 平面、四辺をフレームで固定 | LED 投影スクリーン |
| **Hyperbolic Paraboloid (HP 曲面)** | 双曲放物面 (馬の鞍型) | 屋外パビリオン、ジャングルジム的構造 |
| **Conic (円錐)** | 中心 1 点を吊り、周囲を固定 | テント、巨大ランプシェード |
| **Catenary (懸垂)** | 自重で垂れる曲線 | 緩いドレープ、Christo 系 |
| **Air-supported (空気膜)** | 内圧で膨らむ | エアドーム、巨大バルーン |

## エンジニアが押さえる用語

### 張力 (Tension)

- 単位: **N (ニュートン)** or **N/cm** (単位幅あたり)
- 一般的なテンション幕: **50〜500 N/cm** で運用
- 強い構造 (Christo 級): **2,000 N/cm** 超

張力が強いほどシワが消えるが、布と固定金具の限界が近づく。

### スパン (Span)

固定点間の距離。

| スパン | 想定布 |
|--------|--------|
| 〜1 m | 薄布 (シフォン、トリコット) |
| 1〜5 m | 平織ポリ、厚手シフォン |
| 5〜10 m | テント生地 (PVC コート、PE) |
| 10 m+ | 専用建築膜 (テフロン / シリコン コート ガラス繊維) |

スパンが伸びるほど風で揺れる / たるむ。屋外なら風速 / 雪荷重を計算に入れる。

### サグ (Sag / 弛み)

吊り下げたときの中央の沈み込み。設計値として 「スパンの何 %」 で表す (例: 5% sag = 10m スパンで 50cm 沈む)。

サグが小さいほど張りが強く美しいが、固定金具にかかる力が指数的に増える。

## 固定 (Anchor) のバリエーション

- **ハトメ (Grommet / Eyelet)**: 金属リング、最も汎用。穴の周りの補強が命
- **キーダー (Keder)**: 縁に紐状の芯を縫い込んでチャネルに差し込む。シワが出にくい
- **マジックテープ (Hook & Loop)**: 仮設、テンション控えめ
- **マグネット**: 金属フレーム + マグネット縫い込み。素早く張り替え
- **クリップ**: 縁挟みクランプ。小規模イベント向け
- **熱溶着シーム + ロープ**: 大型 PVC 膜の標準

## フレームと吊り金具

布だけでは構造にならない。**鉄パイプ、アルミトラス、ワイヤーロープ、シャックル、ターンバックル**などの硬質ハードウェアと組み合わせる。

頻出ハードウェア:
- **シャックル (Shackle)** — ロープと布を繋ぐ U 字金具
- **ターンバックル (Turnbuckle)** — 張力を微調整するネジ
- **カラビナ (Carabiner)** — 仮設の繋ぎ
- **ロッキングカム** — ロープを締め込んだ後に固定する金具

## 設計のコツ (実務寄り)

1. **シワが出る箇所は予測できる**: テンションが等方的でない (角・突起・斜めの引き) と必ずシワが寄る。事前にパターン (型紙) を計算するか、3D ソフト (Grasshopper, K2 Engineering) でシミュレーションする
2. **角は補強する**: 角ほど応力集中する。コーナーに**当て布 (パッチ)** を縫い付ける
3. **シーム (継ぎ目) は隠す方向に**: 観客の視線方向と平行にすると目立たない
4. **熱で伸縮するので 5〜10% 余裕**: 朝設置と夜本番で布の張りが変わる
5. **撤収を考えて設計**: 仮設なら 1〜2 時間で撤収できる構造に

## ソフトウェア / 解析ツール

- **Grasshopper + Kangaroo** (Rhino プラグイン) — 膜構造の形状探査
- **K2 Engineering** (Rhino) — 物理シミュレーション
- **Form-finding** (専門 CAD) — 大型膜構造用、建築事務所が使う
- 軽量検討なら **Blender の Cloth Simulation** でも当たりは取れる

## 代表作 / 事例

- **Frei Otto** (建築家、テント構造の祖。1972 ミュンヘン五輪スタジアム)
- **Christo & Jeanne-Claude** "The Gates" (Central Park, 2005) — 7,500 個の橙色幕門
- **Numen / For Use** "String Installations" — テンション糸の塊で人が登れる構造を作る
- **Janet Echelman** "1.78" シリーズ — 巨大な吊り網彫刻、空中を浮遊する
