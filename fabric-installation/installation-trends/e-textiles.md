# E-textiles (電子化したファブリック)

電気を通す / センサとして機能する / 発光する繊維を織り込んだ布。「テキスタイル × エレクトロニクス」の融合領域。

## 何ができるか

| カテゴリ | 機能 | 例 |
|---------|------|-----|
| **発光** | LED, 光ファイバ織り込み | "光る布" |
| **入力 (センサ)** | タッチ、感圧、伸縮、温度 | スマートクッション、衣服センサ |
| **出力 (アクチュエータ)** | 形状変化 (SMA)、振動 | 自律変形ファブリック |
| **データ伝送** | 導電糸でケーブル代替 | 配線を布に内蔵 |
| **発電 / 蓄電** | 圧電繊維、太陽電池織り込み | エナジーハーベスト服 |

## 主要な「電気を通す繊維」

| 繊維 / 製品 | 特徴 | メーカー |
|------------|------|---------|
| **導電糸 (Stainless Steel Thread)** | 細いステンレス線。ミシン縫いも刺繍も可 | Bekinox (Bekaert), Karl Grimm |
| **銀コート繊維** | 銀メッキした合成繊維。柔らかく抗菌性も | Shieldex |
| **導電ファブリック** | 完全に電気を通す布、シールド用 | Less EMF, Statex |
| **カーボン繊維紐** | 軽量、抵抗値中程度 | 多数 |
| **液体金属** | ガリウム合金、流れる電気回路 | 研究段階 |

抵抗値は **数 Ω/m 〜数 kΩ/m**。回路設計のとき抵抗を計算に入れる。

## センサ系テキスタイル

### 1. 感圧 (Pressure)

- 導電糸 + 抵抗布のサンドイッチ構造
- 圧力で抵抗が下がる → アナログ読み取り
- **EeonTex** (Eeonyx 社) など市販あり

### 2. 伸縮 (Stretch)

- 伸縮性のある導電糸 (例: 銀コートライクラ)
- 引っ張ると抵抗が変わる
- ウェアラブル、リハビリ、衣服センシング

### 3. タッチ (Capacitive)

- 導電糸を電極にして静電容量変化を検出
- Arduino + 容量センサライブラリで実装可
- スマートクッション、ボタン代替

### 4. 温度 (Thermochromic, Thermistor 織り込み)

- 温度で色が変わる (熱変色顔料染め)
- または NTC サーミスタを糸として織り込む

## 発光系テキスタイル

### LED 直接縫い付け

- **Lilypad LED** (SparkFun の Arduino エコシステム)
- 導電糸で配線、針穴サイズ
- 工作的なアプローチ、低コスト

### 光ファイバ織り込み

- プラスチック光ファイバを織り込む
- 端面に LED → 全体が点状に光る
- **LumiGram**, **Luminex** (商業製品)

### エレクトロルミネッセンス (EL ワイヤ / シート)

- 薄く曲げられる発光体
- 衣装やワンポイント装飾

## 制御系

### マイコン

- **Arduino / Adafruit Flora / Lilypad** — 衣類装着向けマイコン
- **Raspberry Pi** — リッチ処理 / ネット接続
- **ESP32** — Wi-Fi/BLE 付き、衣服 IoT

### 接続

導電糸の接続は弱点。対策:
- **クリンプ端子** で機械的圧着
- **導電性接着剤** (シルバーペースト)
- **マグネット端子** (脱着可能)

### 洗濯

e-textiles の鬼門。**洗える / 洗えない** を最初に決める。
- 洗える: 樹脂封止、防水加工
- 洗えない: 仮設インスタレーション専用

## インスタレーションでの使い方

### パターン A: タッチ反応ファブリック

来場者が触れると色が変わる / 音が鳴る / 投影が変わる。導電糸 + 容量センサ + Arduino + 他出力 (LED/音/映像)。

### パターン B: 群衆検知ファブリック

床敷きにして人数 / 位置を取る。感圧布 + マイコン + ビジュアル連携。

### パターン C: 自律発光ファブリック

センサなしで内蔵プログラムで光らせる。LED + 光ファイバ + マイコン。

### パターン D: ネットワーク連動

複数のテキスタイルを Wi-Fi で繋ぎ、同期発光 / リアクション。空間全体が反応するインスタ。

- 海外: **Adafruit**, **SparkFun**, **Less EMF**, **Statex**

## エンジニア視点の注意点

1. **抵抗値が高い (1 Ω/m 超)** → LED 駆動に電圧降下を考慮
2. **接続部が断線しやすい** → 機械的補強必須
3. **電源** → 衣服内ならコイン電池、インスタなら USB / 据置電源
4. **配線設計** → 布の伸縮方向に沿って配線、ジグザグで余裕を持たせる
5. **シミュレーション困難** → 試作して測るのが結局早い
