## 1. ファブリックとは

- ファブリック = **布**、という理解でよい
- インスタレーションでよく使われている素材
- だからこそ、**使うにあたって性質を理解しておきたい**、という趣旨

→ 関連: [basics/](basics/)

## 2. ファブリックを使った作例

- ファブリックを使った作例を**ざっと並べる**
- ここで「ファブリックがどのような企画に落とし込まれているのか」をざっくり理解してもらう
- なるべく**幅広く**作例を見せる

→ 関連: [installation-trends/case-studies.md](installation-trends/case-studies.md)

## 3. ファブリックのインスタレーションの利点

- 軽い
- 折り畳める
- 空間を広く占有できる
- プロジェクション / ライト / レーザーとの相性がいい
- 柔らかい表現
- 動きがある
- 平面かつ立体である
- 透過させる
- 質感がある
- 触れることができる（ハプティックな魅力）
- ウェアラブルな表現 など

→ 関連: [planning-hints.md](planning-hints.md)

## 4. ファブリックの種類と性質

- **材料**、**紡績**
- **組織**
  - 織（三大組織）
  - ニット
  - ネット
  - 不織布 など
- **染**
  - 糸染め / 後染め
  - 染料 / 顔料
  - プリント
  - 後加工による機能追加 など
- **工程**も簡単に説明する
  - 例）デニムができるまで：
    紡績 → 糸染め（インディゴの**酸化結合**による）→ 綾織 → ウェザリング
- **道具**も紹介する
  - **ジャガード織り機**
    - **カードによるオンオフ**があり、それで**綜絖（そうこう）の上げ下げ**による**経糸（たていと）の上下**をコントロールする
    - これは**コンピューターとの親和性が高い**
    - **コンピュータジャガード**がある

→ 関連: [basics/fiber-types.md](basics/fiber-types.md)（材料）, [basics/weaving-knitting.md](basics/weaving-knitting.md)（紡績・組織・ジャガード・デニム工程）, [basics/dyeing-finishing.md](basics/dyeing-finishing.md)（染・プリント）

## 5. どこに注目すべきか

- 例えば、**布によっての見え感の違い**があるということ
- **反射・拡散・透過**などによって、見え方や風合いに違いが生まれる
- 材料による変化ももちろんあるが、**組織（構造）の影響が大きい**というところに言及
- **3DCG のテクスチャの考え方**と絡めると分かりやすいかも

→ 関連: [basics/physical-properties.md](basics/physical-properties.md)

## 6. 後加工での機能性追加

布は織り・編みのあと、**後加工**でさらに機能や表情を足せる。

- 難燃
- 超撥水
- 起毛
- スパッタリング（金属塗布加工）
- オパールプリント（オパール加工 / 抜染で部分的に透ける）
- ケミカルレース（土台を溶かしてレース状にする）
- 箔プリント
- フロッキープリント（短繊維を植毛して起毛状にする）
- 熱によるプリーツ加工 など

→ 関連: [basics/dyeing-finishing.md](basics/dyeing-finishing.md)（後加工の詳細）

## 7. 手近な使用例（個人的に）

身近に見られる / 印象的な使用例を個人的に挙げてみる。

- チームラボボーダレスのプロジェクション面の工夫
- 大巻伸嗣のオーガンジーを用いた一連の作品 など

→ 関連: [installation-trends/case-studies.md](installation-trends/case-studies.md)
