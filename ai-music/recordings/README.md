# 録音素材アーカイブ

自分で録音した素材 (フィールドレコーディング、声、物音) を保管する。AI 音楽生成の起点として使う。

`archive/` (AI で生成した曲) とは別物。**`recordings/` は人間が録音した原料、`archive/` は AI が生成した完成品。**

## ディレクトリ構成

```
recordings/
├── README.md              # このファイル
├── voice/                 # 声、呼吸、ハミング
├── environment/           # 環境音 (雨、風、街、室内)
├── objects/               # 物音 (ガラス、金属、紙、水)
├── ambience/              # 空間音 (部屋鳴り、無音録音)
└── misc/                  # その他、分類保留
```

カテゴリは増やす・統合する自由でよい。最初は粗くでいい。

## 命名規則

`YYYYMMDD_<場所or対象>_<番号>.wav` を基本形に。

例:
- `20260601_kitchen-fridge_01.wav` — キッチン冷蔵庫の音
- `20260601_voice-whisper_03.wav` — 囁き声、3 テイク目
- `20260603_rain-window_01.wav` — 窓越しの雨音
- `20260605_glass-ping_02.wav` — グラスを指で弾いた音

短く・後で grep しやすく。複数テイクは末尾の連番で。

## メタデータ (任意)

長尺・重要な素材には併設の `.md` を作る。短いものは不要。

例: `20260601_kitchen-fridge_01.md`

```markdown
# 20260601 kitchen-fridge_01

## 録音条件
- 場所: 自宅キッチン
- 機材: iPhone (Voice Memos)
- 距離: 冷蔵庫から 30cm
- 時間: 深夜 (他の音少ない)

## 内容
冷蔵庫のコンプレッサー音、約 2 分。低周波の安定したハム。

## 使用予定
- ドローンアンビエントのベース層に
- ローパスで処理して bass underlay に

## 後処理
- Audacity でハイパスフィルタ 40Hz 適用済み (空調ノイズ除去)
```

## ファイル形式

- **WAV** 推奨 (無圧縮、後処理に耐える)
- **48kHz / 24bit** が理想、無理なら 44.1kHz / 16bit でも十分
- **MP3** は最終出力用、原料は WAV で残す

## 整音 (Audacity 使う場合)

録音直後にやる最低限の処理:

1. **無音区間カット** (前後の余白を削る)
2. **ノイズリダクション** (Effect → Noise Reduction、ノイズプロファイル取得後適用)
3. **ノーマライズ** (Effect → Normalize、ピークを -3dB に揃える)
4. **フェードイン/アウト** (両端 0.5 秒程度)
5. **WAV で書き出し**

Audacity は無料: [audacityteam.org](https://www.audacityteam.org/)

## .gitignore の検討

録音素材も容量が膨らみやすい。判断:

- **入れる**: バージョン管理・他マシン同期が利く
- **入れない**: `recordings/**/*.wav`, `recordings/**/*.mp3` を `.gitignore`、`.md` のメタだけ管理

**初期推奨**: 素材も git には入れず、別途 OneDrive で同期される `til/` 配下に置く形でファイル自体は残す (= git の管理対象外、OneDrive の同期対象)。`til/.gitignore` に下記追記:

```gitignore
ai-music/recordings/**/*.wav
ai-music/recordings/**/*.mp3
ai-music/recordings/**/*.flac
ai-music/recordings/**/*.m4a
```

## アップロードのチェック

Suno/Udio に上げる前に:

- **長さ**: Suno Free=60秒以内、Pro/Premier=8 分以内、Udio=有料プランで制限要確認
- **権利**: 自分で録音したものか確認。公共空間の会話・楽曲は不可
- **品質**: 極端なノイズ、クリッピングはあらかじめ修正
- **ファイルサイズ**: 各サービスのアップロード上限を確認 (大抵 100MB 以下)

## 録音のヒント

- **マイクを近づける**: ノイズ比 (SN比) が良くなる。アンビエント素材は **多少のノイズが味になる**ので神経質にならなくていい
- **複数テイク取る**: 同じ対象を 3〜5 テイク取って、後で選別
- **音が止んだ後も録り続ける**: 「鳴り終わった後の余韻」が一番味のある素材になることが多い
- **環境音は長めに**: 30 秒以上あると AI 拡張の起点として扱いやすい
- **小さい音を狙う**: 大きな音より小さな音の方がアンビエント向き (冷蔵庫、時計、自分の呼吸)
